---Pseudo Instructions---
Pseudo instructions work like macros, but are built into the assembler.

Loops:
    loop my_loop {
        continue my_loop
        break my_loop    
    }
equivalent to
    my_loop.start:
    jp my_loop.start
    jp my_loop.break
    jp :+
    my_loop.break:
loopr is also valid for jr instructions

Pushpop:
preserves r16 registers around the scope. 
pushpop bc de af {

}

loops with a inc or dec register adds too many hidden costs. Better make it an infinite loop with break and continue features and let the user decide how to iterate. if statements also makes it easier for them. 

I could also use these data structures to define rodata in ROM. I should probably make a separate rodata file instead of letting devs type it in the source. Allow arrays to be set with strings, they use the charmap

Leftover for ROM struct allocations
To allocate a constant struct in ROM, you just use the following syntax.
```
coin := Coin{
    normal_value = 6
    multiplier_value = 7
}
```
Dereferencing the address at *coin.normal_value* will then give you the value 6.

```
sign := Sign{
    text = "This way"
}
// sign is 2 bytes, but the text string is stored after the struct finishes.
// That means that the next allocated string will be 10 bytes away from sign.
// To get the size of the string use sign.text.string_size
```

There is no charmap by default. Instead strings are just ascii mapped. The user has to create their own new charmap if they want to change it, any non set character will be ascii. You have to use the with keyword after a string to use your charmap
```
text = "Hello" with my_charmap 
```
