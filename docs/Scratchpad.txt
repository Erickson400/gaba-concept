---Leftover from ROM struct allocations
To allocate a constant struct in ROM, you just use the following syntax.
```
coin := new Coin {
    normal_value = 6
    multiplier_value = 7
}
```
Dereferencing the address at *coin.normal_value* will then give you the value 6.

```
sign := new Sign {
    text = "This way"
}
// sign is 2 bytes, but the text string is stored after the struct finishes.
// That means that the next allocated string will be 10 bytes away from sign.
// To get the size of the string use sign.text.string_size
```
